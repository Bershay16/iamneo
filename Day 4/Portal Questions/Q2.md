# Question 2 — Sum Finder Solutions

## Problem Statement

"SumFinder Solutions," a research organization, is developing a system to analyze how different numbers can sum up to a target value.

Given a target sum `n` and a minimum number `m`, the goal is to determine the number of ways to form `n` using numbers greater than or equal to `m`.

Each combination must include only values that are at least `m`.

**The order of numbers does not matter.**

Write a program for the same.

---

## Note

**Use Dynamic Programming.**

# Dynamic Programming Approach

We use a one-dimensional DP array.

Let:

```text
dp[i] = number of ways to form sum i
```

Initially:

```text
dp[0] = 1
```

This means there is exactly one way to form sum `0`:

```text
choose nothing
```

Then we consider every number from `m` to `n`.

For every number `x`, we update:

```text
dp[j] = dp[j] + dp[j - x]
```

where:

```text
j >= x
```

---

# Why Does This Avoid Duplicate Orders?

Suppose:

```text
n = 3
m = 1
```

The possible combinations are:

```text
1 + 1 + 1
1 + 2
3
```

We do **not** count:

```text
2 + 1
```

separately.

This happens because we process the possible numbers in increasing order:

```text
1
2
3
...
```

Therefore, combinations are counted without considering different arrangements.

---

# DP Example

For:

```text
n = 3
m = 1
```

Initially:

```text
dp = [1, 0, 0, 0]
```

Process number `1`:

```text
dp = [1, 1, 1, 1]
```

Process number `2`:

```text
dp[2] = dp[2] + dp[0]
      = 1 + 1
      = 2

dp[3] = dp[3] + dp[1]
      = 1 + 1
      = 2
```

Now:

```text
dp = [1, 1, 2, 2]
```

Process number `3`:

```text
dp[3] = dp[3] + dp[0]
      = 2 + 1
      = 3
```

Final:

```text
dp = [1, 1, 2, 3]
```

Therefore:

```text
dp[3] = 3
```

# Java Solution

```java
import java.util.*;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int m = sc.nextInt();

        int[] dp = new int[n + 1];

        dp[0] = 1;

        for (int i = m; i <= n; i++) {
            for (int j = i; j <= n; j++) {
                dp[j] += dp[j - i];
            }
        }

        System.out.println(dp[n]);
    }
}
```

## Step 1 — Read Input

```java

```


means:

```text
n = 10

```

## Step 2 — Create DP Array

```java
int[] dp = new int[n + 1];
```

The array stores the number of ways to create every sum from:

```text
0 to n
```

---

## Step 3 — Initialize dp[0]

```java
dp[0] = 1;
```

There is one way to create sum `0`:

```text
choose nothing
```

This is important because it allows the first number to be added.

---

## Step 4 — Consider Numbers from m to n

```java
for (int i = m; i <= n; i++)
```

If:

```text
m = 2
n = 10
```

we consider:

```text
2, 3, 4, 5, 6, 7, 8, 9, 10
```

---

## Step 5 — Update DP

```java
for (int j = i; j <= n; j++) {
    dp[j] += dp[j - i];
}
```

Here:

```text
j
```

is the current sum.

And:

```text
j - i
```

is the remaining sum after using number `i`.

So:

```text
dp[j] += dp[j - i]
```

means:

> Add all the ways of forming `j - i` to the ways of forming `j`.

---

# Important Point

The order of the loops is important.

Correct:

```java
for (int i = m; i <= n; i++) {
    for (int j = i; j <= n; j++) {
        dp[j] += dp[j - i];
    }
}
```

This counts **combinations**, where order does not matter.

Do not reverse the loops because that can count different arrangements separately.
