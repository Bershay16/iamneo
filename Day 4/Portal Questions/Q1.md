# Question 1 — Number of Ways to Get a Given Sum Using Dice

## Topic
**Dynamic Programming — Counting / Number of Ways**

---

## Problem Statement

Given dice, each with `m` faces numbered from `1` to `m`, determine the number of ways to get a given sum `X`.

`X` is the summation of the values on each face when all the dice are thrown.

### Note

Use **Dynamic Programming** to solve this problem.

---

## Example

### Input

```text
faces = 4
throws = 2
sum = 4
```

### Output

```text
3
```

### Explanation

The ways to reach a sum equal to `4` in `2` throws are:

```text
(1, 3)
(2, 2)
(3, 1)
```

Therefore, the answer is:

```text
3
```

---

The input consists of three integers separated by spaces:

## Approach

Use a 2D Dynamic Programming table:

```text
dp[i][j]
```

where:

- `i` = number of dice thrown
- `j` = current sum
- `dp[i][j]` = number of ways to obtain sum `j` using `i` dice

### Base Case

With zero dice, there is exactly one way to obtain sum `0`:

```text
dp[0][0] = 1
```

### Transition

For every possible face value `k`:

```text
dp[i][j] += dp[i-1][j-k]
```

provided:

```text
j >= k
```

The answer is:

```text
dp[n][X]
```

---

## Java Code

```java
import java.util.*;

class Main {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int faces = sc.nextInt();
        int n = sc.nextInt();
        int sum = sc.nextInt();

        int[][] dp = new int[n + 1][sum + 1];

        dp[0][0] = 1;

        for (int i = 1; i <= n; i++) {
            dp[i][0] = 0;
        }

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= sum; j++) {

                for (int k = 1; k <= faces; k++) {

                    if (j >= k) {
                        dp[i][j] += dp[i - 1][j - k];
                    }
                }
            }
        }

        System.out.println(dp[n][sum]);
    }
}
```

## Key Idea

To calculate the number of ways to obtain a sum using `n` dice, consider the value obtained from the **last die**.

If the last die gives value `k`, then the remaining `n - 1` dice must produce:

```text
sum - k
```

Therefore:

```text
dp[i][j] =
    dp[i-1][j-1]
  + dp[i-1][j-2]
  + ...
  + dp[i-1][j-faces]
```

Only valid values where `j >= k` are considered.
