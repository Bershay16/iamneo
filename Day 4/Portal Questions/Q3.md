# Question 3 — Employee Salary Management Using Inheritance

## Topic

**Object-Oriented Programming — Inheritance, Classes, Objects, Constructors, Method Implementation**

---

## Problem Statement

Rahul is developing a small application for a company to manage employee salary details.

Every employee has a name and employee ID, but full-time employees also receive a basic salary and bonus. Rahul wants to reuse common properties using inheritance and calculate the total salary of a full-time employee.

Create a base class named `Employee` to store common details and a derived class named `FullTimeEmployee` to calculate and display the total salary.

### Formula

```text
totalSalary = basicSalary + bonus
```

---

## Input Format

The input consists of four lines:

- The first line contains an integer `employeeId`.
- The second line contains a string `employeeName`, which may contain spaces.
- The third line contains an integer `basicSalary`.
- The fourth line contains an integer `bonus`.

---

## Output Format

Print the following three lines:

Employee ID: employeeId

## Java Code

```java
import java.util.*;

class Employee {
    int basicSalary;
    int bonus;

    Employee(int bs, int b) {
        basicSalary = bs;
        bonus = b;
    }
}

class FullTimeEmployee extends Employee {
    int id;
    String name;

    FullTimeEmployee(int bs, int b, int i, String s) {
        super(bs, b);
        id = i;
        name = s;
    }

    int salary() {
        return basicSalary + bonus;
    }

    void print() {
        System.out.println("Employee ID: " + id);
        System.out.println("Employee Name: " + name);
        System.out.println("Total Salary: " + salary());
    }
}

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int id = sc.nextInt();
        sc.nextLine();

        String name = sc.nextLine();

        int bs = sc.nextInt();
        int b = sc.nextInt();

        FullTimeEmployee fte =
            new FullTimeEmployee(bs, b, id, name);

        fte.print();
    }
}
```

---

## Important OOP Structure

### Base Class — `Employee`

The `Employee` class contains the common salary-related properties:

```text
basicSalary
bonus
```

Its constructor initializes these values.

---

### Derived Class — `FullTimeEmployee`

`FullTimeEmployee` inherits from `Employee`:

```java
class FullTimeEmployee extends Employee
```

It additionally stores:

```text
id
name
```

It uses:

```java
super(bs, b);
```

to call the constructor of the parent class.

---

### Salary Calculation

The total salary is calculated using:

```java
return basicSalary + bonus;
```

For example:

```text
basicSalary = 20000
bonus = 3000

totalSalary = 20000 + 3000
            = 23000
```

---

## Key Concept

The main purpose of this question is to demonstrate **inheritance**.

Instead of storing all employee information again inside `FullTimeEmployee`, the derived class reuses the properties and constructor of `Employee`.

```text
Employee
   |
   | extends
   ↓
FullTimeEmployee
```

The parent class handles the common salary information, while the child class handles the full-time employee-specific information and salary calculation.
