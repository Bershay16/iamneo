# Question 4 — Student Percentage Using Interface

## Topic

**Object-Oriented Programming — Interface, Classes, Method Implementation, Polymorphism**

---

## Problem Statement

Joseph wants to write a program to implement the abstract class `Marks` with the following method:

```text
getPercentage()
```

Create a class `A` that implements `Marks` and has 3 attributes:

```text
Marks1
Marks2
Marks3
```

The `getPercentage()` method should calculate the percentage of Student A.

Create a class `B` that implements `Marks` and has 4 attributes:

```text
Marks1
Marks2
Marks3
Marks4
```

The `getPercentage()` method should calculate the percentage of Student B.

Each mark is out of 100.

Find the percentage for two students: Student A and Student B.

The output should be rounded to two decimal places.

### Formula

For Student A:

```text
Percentage = (Total Marks / 300.0) × 100
```

For Student B:

```text
Percentage = (Total Marks / 400.0) × 100
```

Since each mark is already out of 100, this is equivalent to calculating the average of the marks.

## Java Code

```java
import java.util.*;

interface Marks {
    double getPercentage();
}

class A implements Marks {
    int m1, m2, m3;

    public double getPercentage() {
        return (double)(m1 + m2 + m3) / 3;
    }
}

class B implements Marks {
    int m1, m2, m3, m4;

    public double getPercentage() {
        return (double)(m1 + m2 + m3 + m4) / 4;
    }
}

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        A a = new A();
        B b = new B();

        a.m1 = sc.nextInt();
        a.m2 = sc.nextInt();
        a.m3 = sc.nextInt();

        b.m1 = sc.nextInt();
        b.m2 = sc.nextInt();
        b.m3 = sc.nextInt();
        b.m4 = sc.nextInt();

        System.out.printf("%.2f\n", a.getPercentage());
        System.out.printf("%.2f", b.getPercentage());
    }
}
```

---

## Simple Explanation

### 1. Interface `Marks`

The interface defines the method:

```java
double getPercentage();
```

It tells the classes that they must provide their own implementation of `getPercentage()`.

---

### 2. Class `A`

Class `A` has three marks:

```text
m1, m2, m3
```

So its percentage is:

```text
(m1 + m2 + m3) / 3
```

For example:

```text
50 + 70 + 60 = 180

180 / 3 = 60.00
```

---

### 3. Class `B`

Class `B` has four marks:

```text
m1, m2, m3, m4
```

So its percentage is:

```text
(m1 + m2 + m3 + m4) / 4
```

For example:

```text
65 + 66 + 78 + 89 = 298

298 / 4 = 74.50
```

---

### 4. Why `%.2f`?

```java
System.out.printf("%.2f", value);
```

`%.2f` means:

- `f` → floating-point number
- `.2` → display exactly 2 digits after the decimal point

Therefore:

```text
60 → 60.00
74.5 → 74.50
86.6666 → 86.67
```

---

## Key Concept

Both classes implement the same interface:

```text
        Marks
       /     \
      /       \
     A         B
```

Both classes have the same method:

```java
getPercentage()
```

but each class calculates the percentage according to its own number of marks.
