# Question 6 — SQL JOIN Queries

## Problem Statement

Alex, a data analyst at an electronics retailer, has been assigned the task of analyzing product return data to help the company better understand customer return patterns.

To perform this analysis, Alex needs to join data from two tables:

- `PRODUCTS`
- `RETURNS`

The task is to retrieve different details about products and their returns using **LEFT OUTER JOIN**.

# Tasks to Perform

## Task 1 — Maximum Return Amount for Each Product

Write a query to retrieve:

- `PRODUCT_ID`
- `PRODUCT_NAME`
- Maximum `RETURN_AMOUNT`
- `RETURN_DATE`

The maximum return amount should have the alias:

`MAX_RETURN_AMOUNT`

Join the `PRODUCTS` table with the `RETURNS` table on `PRODUCT_ID` using a **LEFT OUTER JOIN**.

### Query

```sql
SELECT p.PRODUCT_ID,
       p.PRODUCT_NAME,
       MAX(r.RETURN_AMOUNT) AS MAX_RETURN_AMOUNT,
       r.RETURN_DATE
FROM PRODUCTS p
LEFT OUTER JOIN RETURNS r
ON p.PRODUCT_ID = r.PRODUCT_ID
GROUP BY p.PRODUCT_ID, p.PRODUCT_NAME, r.RETURN_DATE;
```

### Output

```text
PRODUCT_ID  PRODUCT_NAME  MAX_RETURN_AMOUNT  RETURN_DATE
P1          Laptop        150.00             2024-07-01
P2          Smartphone    200.00             2024-07-02
P3          Headphones    50.00              2024-07-03
P4          TV            300.00             2024-07-04
P5          Mouse         25.00              2024-07-05
```

# Task 2 — Returns Greater Than Average

Write a query to retrieve:

- `RETURN_ID`
- `PRODUCT_ID`
- `RETURN_AMOUNT`
- `RETURN_DATE`
- `PRODUCT_NAME`
- `CATEGORY`

Only display returns where the `RETURN_AMOUNT` is greater than the average `RETURN_AMOUNT` across all returns.

Join the `RETURNS` table with the `PRODUCTS` table using a **LEFT OUTER JOIN**.

### Query

```sql
SELECT r.RETURN_ID,
       r.PRODUCT_ID,
       r.RETURN_AMOUNT,
       r.RETURN_DATE,
       p.PRODUCT_NAME,
       p.CATEGORY
FROM RETURNS r
LEFT OUTER JOIN PRODUCTS p
ON r.PRODUCT_ID = p.PRODUCT_ID
WHERE r.RETURN_AMOUNT > (
    SELECT AVG(RETURN_AMOUNT)
    FROM RETURNS
);
```

### Understanding the Average

Return amounts:

```text
150
200
50
300
25
```

Average:

```text
(150 + 200 + 50 + 300 + 25) / 5
= 725 / 5
= 145
```

Therefore, only return amounts greater than `145` are selected:

```text
150
200
300
```

### Output

```text

R1         P1          150.00         2024-07-01   Laptop        Electronics
R2         P2          200.00         2024-07-02   Smartphone    Electronics
R4         P4          300.00         2024-07-04   TV            Electronics
```

# Important Concept — LEFT OUTER JOIN

The basic syntax is:

```sql
SELECT ...
FROM table1
LEFT OUTER JOIN table2
ON table1.column = table2.column;
```

For this question:

```sql
FROM PRODUCTS p
LEFT OUTER JOIN RETURNS r
ON p.PRODUCT_ID = r.PRODUCT_ID
```

## Meaning

A `LEFT OUTER JOIN` keeps **all rows from the left table**.

Here:

```text
LEFT TABLE  = PRODUCTS
RIGHT TABLE = RETURNS
```

Therefore, every product will appear even if it does not have a return.

If a product has no matching return:

```text
RETURN_DATE = NULL
```

# Important SQL Concepts Used

## 1. MAX()

`MAX()` finds the largest value.

```sql
MAX(r.RETURN_AMOUNT)
```

Example:

```text
150
200
50
300
25
```

Maximum:

```text
300
```

---

## 2. AVG()

`AVG()` finds the average value.

```sql
AVG(RETURN_AMOUNT)
```

Example:

```text
(150 + 200 + 50 + 300 + 25) / 5
= 145
```

---

## 3. GROUP BY

`GROUP BY` is used with aggregate functions such as:

- `MAX()`
- `MIN()`
- `SUM()`
- `AVG()`
- `COUNT()`

Example:

```sql
GROUP BY p.PRODUCT_ID, p.PRODUCT_NAME, r.RETURN_DATE;
```

---

## 4. Subquery

A subquery is a query inside another query.

Example:

```sql
WHERE r.RETURN_AMOUNT > (
    SELECT AVG(RETURN_AMOUNT)
    FROM RETURNS
);
```

The inner query:

```sql
SELECT AVG(RETURN_AMOUNT)
FROM RETURNS;
```

calculates the average first.

Then the outer query compares every return amount with that average.

# Exam Shortcuts

## If the question says:

**"Maximum value for each product"**

Think:

```text
MAX() + GROUP BY
```

Template:

```sql
SELECT column1, MAX(column2)
FROM table
GROUP BY column1;
```

---

## If the question says:

**"Greater than the average"**

Think:

```text
AVG() + Subquery + WHERE
```

Template:

```sql
WHERE column > (
    SELECT AVG(column)
    FROM table
);
```

---

## If the question says:

**"Get data from two tables and keep all records from the first table"**

Think:

```text
LEFT JOIN
```

Template:

```sql
SELECT ...
FROM table1
LEFT OUTER JOIN table2
ON table1.id = table2.id;
```
