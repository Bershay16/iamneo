# Question 5 — GROUP BY and HAVING in SQL

## Topic

**SQL — GROUP BY, HAVING, Aggregate Functions**

---

## Problem Statement

Olivia is a data analyst working for a travel agency. She needs to analyze travel package performance and customer preferences using the `TRAVEL_PACKAGES`, `BOOKINGS`, and `CUSTOMERS` tables.

The task is to use `GROUP BY` and `HAVING` clauses to extract the required information.

## Tasks

### 1. Average Package Price by Destination

Calculate the average price for each destination from the `TRAVEL_PACKAGES` table.

Display only destinations where the average price is greater than `1500`.

Use the alias:

```text
avg_price
```

### Query

```sql
SELECT DESTINATION, AVG(PRICE) AS avg_price
FROM TRAVEL_PACKAGES
GROUP BY DESTINATION
HAVING AVG(PRICE) > 1500;
```

---

### 2. Total Tickets for Each Package

Calculate the total number of tickets for each package from the `BOOKINGS` table.

Display only packages where the total number of tickets is greater than `5`.

Use the alias:

```text
total_tickets
```

### Query

```sql
SELECT PACKAGE_ID, SUM(NUMBER_OF_TICKETS) AS total_tickets
FROM BOOKINGS
GROUP BY PACKAGE_ID
HAVING SUM(NUMBER_OF_TICKETS) > 5;
```

---

### 3. Maximum Customer Age in Each City

Calculate the maximum age of customers in each city from the `CUSTOMERS` table.

Display:

- `CITY`
- Maximum age

Use the alias:

```text
max_age
```

### Query

```sql
SELECT CITY, MAX(AGE) AS max_age
FROM CUSTOMERS
GROUP BY CITY;
```

---

### 4. Average Tickets Booked by Each Customer

Calculate the average number of tickets booked by each customer from the `BOOKINGS` table.

Only include customers whose **total number of tickets is greater than 3**.

Display:

- `CUSTOMER_ID`
- Average number of tickets

Use the alias:

```text
avg_tickets
```

Sort the result in ascending order by `CUSTOMER_ID`.

### Query

```sql
SELECT CUSTOMER_ID, AVG(NUMBER_OF_TICKETS) AS avg_tickets
FROM BOOKINGS
GROUP BY CUSTOMER_ID
HAVING SUM(NUMBER_OF_TICKETS) > 3
ORDER BY CUSTOMER_ID ASC;
```

## Complete SQL Code

```sql
SELECT DESTINATION, AVG(PRICE) AS avg_price
FROM TRAVEL_PACKAGES
GROUP BY DESTINATION
HAVING AVG(PRICE) > 1500;

SELECT PACKAGE_ID, SUM(NUMBER_OF_TICKETS) AS total_tickets
FROM BOOKINGS
GROUP BY PACKAGE_ID
HAVING SUM(NUMBER_OF_TICKETS) > 5;

SELECT CITY, MAX(AGE) AS max_age
FROM CUSTOMERS
GROUP BY CITY;
```

## Important Concepts

### GROUP BY

`GROUP BY` combines rows having the same value into groups.

Example:

```sql
GROUP BY CITY
```

creates one group for each city.

---

### HAVING

`HAVING` filters the **groups** created by `GROUP BY`.

Example:

```sql
HAVING SUM(NUMBER_OF_TICKETS) > 5
```

keeps only those groups whose total tickets are greater than 5.

---

### WHERE vs HAVING

```text
WHERE  → filters individual rows
HAVING → filters groups
```

Example:

```sql
SELECT PACKAGE_ID, SUM(NUMBER_OF_TICKETS)
FROM BOOKINGS
GROUP BY PACKAGE_ID
HAVING SUM(NUMBER_OF_TICKETS) > 5;
```

Here, `HAVING` is required because we are filtering based on an aggregate value (`SUM`).

---

## Aggregate Functions Used

```text
AVG() → Average
SUM() → Total
MAX() → Maximum
```

### Quick Pattern

```sql
SELECT column, AGGREGATE_FUNCTION(column)
FROM table
GROUP BY column
HAVING condition;
```
