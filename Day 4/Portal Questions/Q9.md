# MIN and MAX Aggregate Functions

## Problem Statement

Given the MOVIES, REVIEWS, and AWARDS tables, write SQL queries using the MIN and MAX aggregate functions to find the minimum and maximum ratings and the earliest and latest dates and movie names.

## Input Format

The input tables are already created and contain the records given in the problem statement.

## Input Description

- `MOVIES` contains movie IDs, names, and release dates.
- `REVIEWS` contains review IDs, movie IDs, review dates, and ratings.
- `AWARDS` contains award IDs, movie IDs, award dates, and award names.

## Output Format

Display the minimum and maximum values for ratings, release dates, award dates, review dates, and movie names with the required aliases.

## Output Description

The queries produce:

- `MIN_RATING` and `MAX_RATING`
- `EARLIEST_RELEASE_DATE` and `LATEST_RELEASE_DATE`
- `EARLIEST_AWARD_DATE` and `LATEST_AWARD_DATE`
- `EARLIEST_REVIEW_DATE` and `LATEST_REVIEW_DATE`
- `EARLIEST_MOVIE` and `LATEST_MOVIE`

## SQL Code

```sql
SELECT MIN(RATING) AS MIN_RATING, MAX(RATING) AS MAX_RATING
FROM REVIEWS;

SELECT MIN(RELEASE_DATE) AS EARLIEST_RELEASE_DATE,
       MAX(RELEASE_DATE) AS LATEST_RELEASE_DATE
FROM MOVIES;

SELECT MIN(AWARD_DATE) AS EARLIEST_AWARD_DATE,
       MAX(AWARD_DATE) AS LATEST_AWARD_DATE
FROM AWARDS;

SELECT MIN(REVIEW_DATE) AS EARLIEST_REVIEW_DATE,
       MAX(REVIEW_DATE) AS LATEST_REVIEW_DATE
FROM REVIEWS;

SELECT MIN(MOVIE_NAME) AS EARLIEST_MOVIE,
       MAX(MOVIE_NAME) AS LATEST_MOVIE
FROM MOVIES;
```

## Time Complexity

`O(n)` per query

## Space Complexity

`O(1)`
