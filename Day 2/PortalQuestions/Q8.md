# Rat in a Maze

## Problem Statement

Imagine a small robot mouse is placed in a square maze inside a lab. The maze is made up of `N x N` tiles, where each tile can either be open (marked as `1`) or blocked (marked as `0`). The robot starts at the top-left corner of the maze — this is like the entrance of the lab. Its goal is to reach the bottom-right corner, which is the exit.

However, the robot can only move in one of four directions at a time — forward (down), right, backward (up), or left. It cannot move diagonally or go through walls (tiles marked with `0`).

Your task is to help the robot find a valid route from the entrance to the exit using only the open paths (`1`). If a way exists, show the path; if not, indicate that it's trapped in the maze.

Write a program for the same.

## Input Format

The first line of input consists of an integer `N`, representing the size of the `N x N` maze.

The next `N` lines each consist of `N` space-separated integers (0 or 1), representing each row of the maze, where `1` indicates an open path and `0` indicates a blocked cell.

## Output Format

If a valid path is found, print the solution matrix showing the path using `1`s and the rest as `0`s.

Each row should be printed on a new line.

Each number in a row should be separated by a single space.

No extra spaces at the end of each line.

If no path exists, print:

```text
No path found
```

Refer to the sample output for the formatting specification.

## Constraints

* `1 ≤ N ≤ 10`
* Each cell value is either `0` or `1`.

## Approach

1. Start from the top-left cell `(0, 0)`.
2. Create another matrix called `solution` to store the cells that are part of the valid path.
3. Use recursion to explore the four possible directions: down, right, up, and left.
4. A cell can be visited only if:
   - It is inside the maze.
   - It is an open cell (`1`).
   - It has not already been included in the current path.
5. Mark the current cell as `1` in the solution matrix.
6. If the current cell is the bottom-right cell, a valid path has been found.
7. If none of the four directions leads to the destination, remove the current cell from the solution matrix and backtrack.
8. If the recursive function cannot reach the destination, print `No path found`.

## Java Solution

```java
import java.util.Scanner;

class Main {

    static int n;
    static int[][] maze;
    static int[][] solution;

    static boolean isSafe(int row, int col) {
        return row >= 0 && row < n
                && col >= 0 && col < n
                && maze[row][col] == 1
                && solution[row][col] == 0;
    }

    static boolean solveMaze(int row, int col) {
        // Check whether the current cell is valid
        if (!isSafe(row, col)) {
            return false;
        }

        // Add the current cell to the path
        solution[row][col] = 1;

        // Destination reached
        if (row == n - 1 && col == n - 1) {
            return true;
        }

        // Try moving down
        if (solveMaze(row + 1, col)) {
            return true;
        }

        // Try moving right
        if (solveMaze(row, col + 1)) {
            return true;
        }

        // Try moving up
        if (solveMaze(row - 1, col)) {
            return true;
        }

        // Try moving left
        if (solveMaze(row, col - 1)) {
            return true;
        }

        // No direction worked, so backtrack
        solution[row][col] = 0;

        return false;
    }

    static void printSolution() {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (j > 0) {
                    System.out.print(" ");
                }
                System.out.print(solution[i][j]);
            }
            System.out.println();
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        n = sc.nextInt();

        maze = new int[n][n];
        solution = new int[n][n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                maze[i][j] = sc.nextInt();
            }
        }

        if (solveMaze(0, 0)) {
            printSolution();
        } else {
            System.out.println("No path found");
        }

        sc.close();
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(N²)` because each cell is visited at most once during the backtracking search.
* **Space Complexity:** `O(N²)` for the solution matrix and recursive call stack.
