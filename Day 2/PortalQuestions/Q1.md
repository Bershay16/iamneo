# Remove Duplicates from Doubly Linked List

## Problem Statement

You have an unsorted doubly linked list of product IDs. Some product IDs may appear more than once. Remove all duplicate nodes from the list.

Note: Insert elements at the front of the doubly linked list.

## Input Format

The first line contains an integer `n`, representing the number of elements in the list.

The second line contains `n` space-separated integers representing the list elements.

## Output Format

Print the final list after removing duplicate nodes, separated by spaces.

## Code Constraints

- `2 ≤ n ≤ 30`
- `1 ≤ elements in the list ≤ 100`

## Sample Test Cases

### Case 1

Input:
```text
10
12 12 10 4 8 4 6 4 4 8
```

Output:
```text
8 4 6 10 12
```

### Case 2

Input:
```text
4
1 1 2 2
```

Output:
```text
2 1
```

## Java Code

```java
import java.util.*;

class Node {
    int data;
    Node prev, next;

    Node(int data) {
        this.data = data;
    }
}

public class Main {
    static Node head;

    static void insertFront(int data) {
        Node n = new Node(data);
        n.next = head;
        if (head != null)
            head.prev = n;
        head = n;
    }

    static void removeDuplicates() {
        for (Node i = head; i != null; i = i.next) {
            for (Node j = i.next; j != null; ) {
                Node next = j.next;

                if (i.data == j.data) {
                    if (j.prev != null)
                        j.prev.next = j.next;
                    if (j.next != null)
                        j.next.prev = j.prev;
                }

                j = next;
            }
        }
    }

    static void display() {
        for (Node t = head; t != null; t = t.next)
            System.out.print(t.data + " ");
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        for (int i = 0; i < n; i++)
            insertFront(sc.nextInt());

        removeDuplicates();
        display();
    }
}
```

## Complexity

Time: `O(n²)`

Space: `O(n)`
