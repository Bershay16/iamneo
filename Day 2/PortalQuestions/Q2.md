# Doubly Linked List - Append and Remove Last Element

## Problem Statement

Saran is tasked with implementing a doubly linked list in data structures, allowing users to append elements to the end of the list and remove the last element.

Help Saran write a program to append N integers to the doubly linked list and display the list after removing the last element.

## Input Format

The first line contains an integer `n`, representing the size of the list.

The second line contains `n` space-separated integers representing the elements of the list.

## Output Format

Print the elements of the doubly linked list after removing the last element as space-separated integers on a single line.

## Code Constraints

- `2 ≤ n ≤ 50`
- `1 ≤ elements of the list ≤ 10^9`

## Sample Test Cases

## Java Code

```java
import java.util.*;

class Node {
    long data;
    Node prev, next;

    Node(long data) {
        this.data = data;
    }
}

public class Main {
    static Node head, tail;

    static void append(long data) {
        Node n = new Node(data);

        if (head == null) {
            head = tail = n;
        } else {
            tail.next = n;
            n.prev = tail;
            tail = n;
        }
    }

    static void removeLast() {
        if (tail != null) {
            tail = tail.prev;
            if (tail == null)
                head = null;
            else
                tail.next = null;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        for (int i = 0; i < n; i++)
            append(sc.nextLong());

        removeLast();

        for (Node t = head; t != null; t = t.next)
            System.out.print(t.data + " ");
    }
}
```

## Complexity

Time: `O(n)`

Space: `O(n)`
