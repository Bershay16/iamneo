# Find Middle Element of a Singly Linked List

## Problem Statement

Dev is tasked with creating a program that efficiently finds the middle element of a linked list. The program should take user input to populate the linked list by inserting each element into the front of the list and then determine the middle element.

Assist Dev, as he needs to ensure that the middle element is accurately identified from the constructed singly linked list:

- If it's an odd-length linked list, return the middle element.
- If it's an even-length linked list, return the second middle element of the two elements.

## Input Format

The first line of input consists of an integer `n`, representing the number of elements in the linked list.

The second line consists of `n` space-separated integers, representing the elements of the linked list.

## Output Format

The first line of output displays the linked list after inserting elements at the front.

The second line displays `Middle Element:` followed by an integer representing the middle element of the linked list.

Refer to the sample output for formatting specifications.

## Constraints

* `1 ≤ n ≤ 30`
* `1 ≤ elements ≤ 100`

## Sample Test Cases

### Case 1

**Input**

```text
5
10 20 30 40 50
```

**Output**

```text
50 40 30 20 10
Middle Element: 30
```

### Case 2

**Input**

```text
4
10 20 30 40
```

**Output**

```text
40 30 20 10
Middle Element: 20
```

## Approach

1. Create a `Node` class to store the value and the reference to the next node.
2. Create an `SLL` class to manage the singly linked list.
3. Insert every element at the front of the linked list using `insertAtBeg()`.
4. Display the linked list from the head to the end.
5. Traverse the linked list once to count the total number of elements.
6. Calculate the middle position:
   - For an odd number of elements, it is the middle element.
   - For an even number of elements, choose the second middle element.
7. Traverse the list again until the calculated middle position is reached.
8. Print the value of that node as the middle element.

## Java Solution

```java
import java.util.*;

class Node {
    int value;
    Node next;

    Node() {
    }

    Node(int value) {
        this.value = value;
    }
}

class SLL {
    Node head = null;

    SLL() {
    }

    SLL(int value) {
        head = new Node(value);
    }

    void insertAtBeg(int value) {
        Node temp = new Node(value);

        temp.next = head;
        head = temp;
    }

    void display() {
        Node temp = head;

        while (temp != null) {
            System.out.print(temp.value);

            if (temp.next != null) {
                System.out.print(" ");
            }

            temp = temp.next;
        }

        System.out.println();
    }

    void findMiddle() {
        Node temp = head;
        int count = 0;

        // Count the number of elements
        while (temp != null) {
            count++;
            temp = temp.next;
        }

        // Find the position of the second middle element
        int mid = (count + 1) / 2;

        if (count % 2 == 0) {
            mid++;
        }

        temp = head;
        count = 1;

        // Traverse to the middle position
        while (temp != null) {
            if (count == mid) {
                System.out.println("Middle Element: " + temp.value);
                return;
            }

            temp = temp.next;
            count++;
        }
    }
}

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        SLL list = new SLL();

        for (int i = 0; i < n; i++) {
            list.insertAtBeg(sc.nextInt());
        }

        list.display();
        list.findMiddle();
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(N)`
* **Space Complexity:** `O(N)` for storing the linked list.
