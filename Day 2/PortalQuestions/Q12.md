# Decode Increasing and Decreasing Sequence

## Problem Statement

The task is to decode a sequence of length at most 8, where the sequence consists of the letters `I` and `D`. `I` represents an increasing sequence, while `D` represents a decreasing sequence. The decoded sequence should consist of a minimum number with no repeated digits.

### Example

**Input**

```text
DI
```

**Output**

```text
213
```

### Explanation

For each element of the given sequence, insert its position index + 1 into a stack that stores it in FILO order. If the current character is increasing `I`, or all characters of the input sequence are processed, pop all numbers from the stack and append them to the output string.

The input should contain only uppercase characters `I` and `D`.

## Input Format

Input should consist of a String.

## Output Format

The output should be the decoded version of the input.

## Constraints

* The input string consists only of uppercase characters `I` and `D`.
* `1 ≤ length of the sequence ≤ 8`

## Approach

1. First, check whether the input contains only uppercase `I` and `D` characters.
2. Use a stack to temporarily store numbers.
3. Start numbering from `1`.
4. Push the current number into the stack for every character.
5. When an `I` is encountered, pop all elements from the stack and append them to the result.
6. For a `D`, continue pushing numbers into the stack so that they are later popped in reverse order.
7. After processing the complete sequence, pop all remaining elements from the stack.
8. The resulting string is the required decoded sequence.

## Java Solution

```java
import java.util.*;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        String s = sc.nextLine();

        // Check for valid input
        for (char ch : s.toCharArray()) {
            if (ch != 'I' && ch != 'D') {
                System.out.println("Invalid input");
                return;
            }
        }

        Stack<Integer> stack = new Stack<>();
        StringBuilder result = new StringBuilder();

        stack.push(1);
        int number = 2;

        for (char ch : s.toCharArray()) {

            if (ch == 'D') {
                stack.push(number);
                number++;
            } else {
                while (!stack.isEmpty()) {
                    result.append(stack.pop());
                }

                stack.push(number);
                number++;
            }
        }

        // Process remaining numbers
        while (!stack.isEmpty()) {
            result.append(stack.pop());
        }

        System.out.println(Integer.parseInt(result.toString()));
    }
}
```
