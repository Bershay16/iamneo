# Singly Linked List Sorting

## Problem Statement

Madhan is tasked with creating a program that manages a singly linked list with the following functionalities:

- Insert elements at the end of the list based on user input.
- Sort the elements of the list in ascending order.
- Display the sorted elements of the list.

Guide him in the task.

## Input Format

The first line of input consists of an integer `N`, which is the number of elements.

The second line consists of `N` space-separated integers.

## Output Format

The output prints the sorted elements of the linked list as space-separated integers.

Refer to the sample output for formatting specifications.

## Constraints

* `1 ≤ N ≤ 10`
* `1 ≤ elements ≤ 100`

## Sample Test Cases

### Case 1

**Input**

```text
5
78 89 34 51 67
```

**Output**

```text
34 51 67 78 89
```

### Case 2

**Input**

```text
7
10 5 20 35 30 15 18
```

**Output**

```text
5 10 15 18 20 30 35
```

## Approach

1. Create a `Node` class to store the value and the reference to the next node.
2. Create an `SLL` class to manage the singly linked list.
3. Insert every input element at the end of the linked list using `insertAtEnd()`.
4. Traverse the linked list and copy its values into an `ArrayList`.
5. Sort the `ArrayList` using `Collections.sort()`.
6. Traverse the linked list again and replace each node's value with the corresponding sorted value.
7. Display the sorted linked list using the `display()` method.

## Java Solution

```java
import java.util.*;

class Node {
    int value;
    Node next;

    Node() {
    }

    Node(int value) {
        this.value = value;
    }
}

class SLL {
    Node head = null;

    SLL() {
    }

    SLL(int value) {
        head = new Node(value);
    }

    void insertAtEnd(int value) {
        // Empty list
        if (head == null) {
            head = new Node(value);
            return;
        }

        // One or more elements
        Node temp = head;

        while (temp.next != null) {
            temp = temp.next;
        }

        temp.next = new Node(value);
    }

    void display() {
        Node temp = head;

        while (temp != null) {
            System.out.print(temp.value + " ");
            temp = temp.next;
        }
    }

    void sort() {
        ArrayList<Integer> list = new ArrayList<>();

        Node temp = head;

        while (temp != null) {
            list.add(temp.value);
            temp = temp.next;
        }

        Collections.sort(list);

        temp = head;
        int i = 0;

        while (temp != null) {
            temp.value = list.get(i);
            i++;
            temp = temp.next;
        }
    }
}

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        SLL list = new SLL();

        for (int i = 0; i < n; i++) {
            list.insertAtEnd(sc.nextInt());
        }

        list.sort();
        list.display();
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(N log N)` for sorting the elements.
* **Space Complexity:** `O(N)` for storing the linked-list values in the `ArrayList`.
