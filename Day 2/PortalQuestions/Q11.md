# Stack Implementation Using Linked List

## Problem Statement

Raghav is learning about stacks and has implemented a simple stack using a linked list. The stack supports three operations: push, pop and display. However, he is facing some issues with the functionality, and he seeks your assistance.

Your task is to help Raghav to achieve the same.

## Input Format

The input consists of choices representing the operation to be performed.

If the choice is `1`, the following input consists of the element to be pushed into the stack.

If the choice is `2`, perform the pop operation.

If the choice is `3`, display the stack.

If the choice is `4`, exit.

If the choice is greater than `4`, print `Wrong choice`.

## Output Format

For each operation, the program should provide appropriate output based on the operation performed.

The output format is as follows:

For push operation: `Node is Inserted`.

For pop operation: `Popped Element:` followed by the popped value or `EMPTY STACK` if the stack is empty.

For display operation: `The stack is:` followed by the stack elements or `EMPTY STACK` if the stack is empty.

For exit operation: The program terminates.

For an invalid choice: `Wrong choice`.

Refer to the sample output for formatting specifications.

## Constraints

* `1 ≤ element value ≤ 10000`
* Choice can be any integer; valid choices are `1`, `2`, `3`, and `4`.
* Invalid choices (any value other than `1–4`) trigger `Wrong choice`.

## Approach

1. Create a `Node` class to store the stack element and the reference to the next node.
2. Create a `Stack` class using the linked list implementation.
3. Maintain a `top` pointer that always points to the top element of the stack.
4. For push operation, create a new node and insert it at the top of the stack.
5. For pop operation, remove the node pointed to by `top` and move `top` to the next node.
6. If `top` is `null`, the stack is empty, so print `EMPTY STACK`.
7. For display operation, traverse the linked list from `top` to the end and print each element.
8. Continue processing choices until choice `4` is received.

## Java Solution

```java
import java.util.Scanner;

class Node {
    int value;
    Node next;

    Node(int value) {
        this.value = value;
        this.next = null;
    }
}

class Stack {
    Node top = null;

    void push(int value) {
        Node newNode = new Node(value);

        newNode.next = top;
        top = newNode;

        System.out.println("Node is Inserted");
    }

    void pop() {
        if (top == null) {
            System.out.println("EMPTY STACK");
            return;
        }

        int element = top.value;
        top = top.next;

        System.out.println("Popped Element: " + element);
    }

    void display() {
        if (top == null) {
            System.out.println("EMPTY STACK");
            return;
        }

        System.out.print("The stack is:");

        Node temp = top;

        while (temp != null) {
            System.out.print(" " + temp.value);
            temp = temp.next;
        }

        System.out.println();
    }
}

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        Stack stack = new Stack();

        while (true) {
            int choice = sc.nextInt();

            switch (choice) {
                case 1:
                    int value = sc.nextInt();
                    stack.push(value);
                    break;

                case 2:
                    stack.pop();
                    break;

                case 3:
                    stack.display();
                    break;

                case 4:
                    return;

                default:
                    System.out.println("Wrong choice");
            }
        }
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(1)` for push and pop, `O(N)` for display.
* **Space Complexity:** `O(N)` for storing the stack elements in the linked list.
