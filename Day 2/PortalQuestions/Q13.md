# Printer Queue Using Linked List

## Problem Statement

You are designing a printer queue for a computer lab. The lab has a printer that can only process one print job at a time. Your task is to implement a queue using a linked list to manage print jobs sent to the printer. Each print job is represented by the number of pages it contains.

Implement the following operations:

- **Enqueue Print Job:** Add a print job to the end of the queue.
- **Dequeue Print Job:** Remove and process the next print job in the queue.
- **Display Queue:** Display the print jobs in the queue.

Your program should handle these operations efficiently to ensure that print jobs are processed in the order they are received.

## Input Format

The first line of input consists of an integer option, representing the operation to be performed.

If option is `1`, the next line consists of an integer number of pages, representing the number of pages in the print job.

If option is `2`, no additional input is required (process print job operation).

If option is `3`, no additional input is required (display queue operation).

If option is `4`, no additional input is required (exit program).

The input continues until option `4` is entered.

## Output Format

For option `1`: The output consists of the string `Print job with X pages is enqueued.` where X is the number of pages.

For option `2`: If the queue is not empty, the output consists of the string `Processing print job: X pages` where X is the number of pages. If the queue is empty, the output consists of the string `Queue is empty.`.

For option `3`: If the queue is not empty, the output consists of the string `Print jobs in the queue: ` followed by space-separated page counts with `pages` suffix from front to rear. If the queue is empty, the output consists of the string `Queue is empty.`.

For option `4`: The program terminates.

For invalid option: The output consists of the string `Invalid option.`.

Refer to the sample output for formatting specifications.

## Constraints

* `1 ≤ option ≤ 4`
* `1 ≤ pages ≤ 10^9`
* Queue is implemented using linked list (unlimited size).

## Approach

1. Create a `Node` class to store the number of pages in a print job and the reference to the next node.
2. Create a `Queue` class using the linked list implementation.
3. Maintain two pointers, `front` and `rear`, to keep track of the first and last print jobs.
4. For option `1`, create a new node and add it to the rear of the queue.
5. For option `2`, remove the node from the front of the queue and process its print job.
6. If the queue is empty during dequeue or display, print `Queue is empty.`.
7. For option `3`, traverse the queue from `front` to `rear` and display all print jobs.
8. For option `4`, terminate the program.
9. For any other option, print `Invalid option.`.

## Java Solution

```java
import java.util.Scanner;

class Node {
    long pages;
    Node next;

    Node(long pages) {
        this.pages = pages;
        this.next = null;
    }
}

class Queue {
    Node front = null;
    Node rear = null;

    void enqueue(long pages) {
        Node newNode = new Node(pages);

        if (rear == null) {
            front = rear = newNode;
        } else {
            rear.next = newNode;
            rear = newNode;
        }

        System.out.println("Print job with " + pages + " pages is enqueued.");
    }

    void dequeue() {
        if (front == null) {
            System.out.println("Queue is empty.");
            return;
        }

        long pages = front.pages;
        front = front.next;

        if (front == null) {
            rear = null;
        }

        System.out.println("Processing print job: " + pages + " pages");
    }

    void display() {
        if (front == null) {
            System.out.println("Queue is empty.");
            return;
        }

        System.out.print("Print jobs in the queue: ");

        Node temp = front;

        while (temp != null) {
            System.out.print(temp.pages + " pages");

            if (temp.next != null) {
                System.out.print(" ");
            }

            temp = temp.next;
        }

        System.out.println();
    }
}

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        Queue queue = new Queue();

        while (sc.hasNextInt()) {
            int choice = sc.nextInt();

            if (choice == 1) {
                long pages = sc.nextLong();
                queue.enqueue(pages);
            } else if (choice == 2) {
                queue.dequeue();
            } else if (choice == 3) {
                queue.display();
            } else if (choice == 4) {
                break;
            } else {
                System.out.println("Invalid option.");
            }
        }
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(1)` for enqueue and dequeue, `O(N)` for display.
* **Space Complexity:** `O(N)` for storing the print jobs in the linked-list queue.
