# Redundant Parentheses

## Problem Statement

Given a string of balanced expressions, find if it contains redundant parentheses or not. A set of parentheses is redundant if the same sub-expression is surrounded by unnecessary or multiple brackets. Print `Yes` if redundant else `No`.

## Input Format

The first and only line of input consists of a string `A`, representing a mathematical expression containing parentheses and operators.

## Output Format

The first and only line of output consists of the string `Yes` if the expression contains redundant braces, or `No` otherwise.

## Constraints

* `1 ≤ |A| ≤ 100`
* String consists of characters: `(`, `)`, `+`, `-`, `*`, `/`, and lowercase letters.
* Expression contains valid parentheses.

## Sample Test Cases

### Case 1

**Input**

```text
(a+b)
```

**Output**

```text
No
```

### Case 2

**Input**

```text
((a+b))
```

**Output**

```text
Yes
```

## Approach

1. Create a stack to store the characters of the expression.
2. Traverse the expression from left to right.
3. Push each character into the stack.
4. When a closing parenthesis `)` is found, remove characters until the matching `(` is found.
5. Check whether there is an operator between the parentheses.
6. If there is no operator, the parentheses are redundant, so print `Yes`.
7. If no redundant parentheses are found, print `No`.

## Java Solution

```java
import java.util.*;

class Solution {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String expression = input.nextLine();
        Stack<Character> stack = new Stack<>();

        for (char ch : expression.toCharArray()) {
            if (ch == ')') {
                boolean hasOperator = false;

                while (!stack.isEmpty() && stack.peek() != '(') {
                    char top = stack.pop();

                    if (top == '+' || top == '-' || top == '*' || top == '/') {
                        hasOperator = true;
                    }
                }

                stack.pop();

                if (!hasOperator) {
                    System.out.println("Yes");
                    return;
                }
            } else {
                stack.push(ch);
            }
        }

        System.out.println("No");
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(N)`
* **Space Complexity:** `O(N)`
