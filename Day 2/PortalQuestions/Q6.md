# Ticket Booking Queue System

## Problem Statement

You are assigned to develop a simple ticket-booking system for a local movie theater. The theater has a single ticket counter, and customers arrive to purchase tickets for the movie of their choice. Implement a queue using linked lists to manage the customers in line at the ticket counter.

Implement a program that provides the following functionalities:

- Enqueue a customer into the ticket line.
- Dequeue the customer at the front of the line when they reach the ticket counter.
- Display the current list of customers in line.

## Input Format

The first line of input consists of an integer option, representing the operation to be performed.

If option is `1`, the next line consists of an integer `customerID`, representing the customer to be enqueued.

If option is `2`, no additional input is required (dequeue operation).

If option is `3`, no additional input is required (display queue operation).

The input continues until end of file.

## Output Format

For option `1`: The output consists of the string `Customer ID X is enqueued` where X is the customer ID.

For option `2`: If queue is not empty, the output consists of the string `Dequeued customer ID: X` where X is the customer ID. If queue is empty, the output consists of the string `No customers in line`.

For option `3`: If queue is not empty, the output consists of the string `Customer IDs in the queue are: ` followed by space-separated customer IDs from front to rear. If queue is empty, the output consists of the string `No customers in line`.

For invalid option: The output consists of the string `Invalid option`.

## Constraints

* `1 ≤ option ≤ 3`
* `1 ≤ customerID ≤ 10^9`
* Queue is implemented using linked list (unlimited size).

## Approach

1. Create a `Node` class to store the customer ID and the reference to the next node.
2. Maintain two pointers, `front` and `rear`, for the queue.
3. For option `1`, create a new node and add it to the rear of the queue.
4. For option `2`, remove the node from the front of the queue.
5. If the queue becomes empty after dequeue, update both `front` and `rear` to `null`.
6. For option `3`, traverse the queue from `front` to `rear` and display all customer IDs.
7. For any other option, print `Invalid option`.
8. Continue processing operations until the input reaches the end of file.

## Java Solution

```java
import java.util.*;

class Solution {

    static class Node {
        long customerId;
        Node next;

        Node(long customerId) {
            this.customerId = customerId;
        }
    }

    static Node front = null;
    static Node rear = null;

    static void enqueue(long customerId) {
        Node newNode = new Node(customerId);

        if (rear == null) {
            front = rear = newNode;
        } else {
            rear.next = newNode;
            rear = newNode;
        }

        System.out.println("Customer ID " + customerId + " is enqueued");
    }

    static void dequeue() {
        if (front == null) {
            System.out.println("No customers in line");
            return;
        }

        System.out.println("Dequeued customer ID: " + front.customerId);

        front = front.next;

        if (front == null) {
            rear = null;
        }
    }

    static void displayQueue() {
        if (front == null) {
            System.out.println("No customers in line");
            return;
        }

        System.out.print("Customer IDs in the queue are:");

        Node current = front;

        while (current != null) {
            System.out.print(" " + current.customerId);
            current = current.next;
        }

        System.out.println();
    }

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        while (input.hasNextInt()) {
            int option = input.nextInt();

            if (option == 1) {
                long customerId = input.nextLong();
                enqueue(customerId);
            } else if (option == 2) {
                dequeue();
            } else if (option == 3) {
                displayQueue();
            } else {
                System.out.println("Invalid option");
            }
        }

        input.close();
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(1)` for enqueue and dequeue, `O(N)` for displaying the queue.
* **Space Complexity:** `O(N)` for storing the customers in the linked list.
