# Coin Change Using Recursion

## Problem Statement

Priya is at a candy store and wants to buy candies worth exactly `M` rupees. The store has coin denominations of `N` different values. She wants to know how many distinct ways she can make the exact amount `M` using the available coins, where each coin can be used any number of times.

Help her implement a recursive function `countWays(int[], int, int)` to find the total number of ways.

Function Specification: `int countWays(int[], int, int)`

## Input Format

The first line of input consists of an integer `n`, representing the number of coin denominations.

The next line consists of `n` space-separated integers, representing the coin denominations.

The next line consists of an integer `m`, representing the target sum to be achieved.

## Output Format

The output prints an integer, representing the total number of ways to make the sum `m` using the given coin denominations.

Refer to the sample output for formatting specifications.

## Constraints

* `1 ≤ n ≤ 10`
* `1 ≤ coin[i] ≤ 100`
* `1 ≤ m ≤ 50`

## Approach

1. Create a recursive function `countWays(coins, n, m)`.
2. If the target amount `m` becomes `0`, return `1` because one valid combination has been formed.
3. If there are no coins left or `m` becomes negative, return `0`.
4. For each recursive step, consider two choices:
   - Include the current coin and continue using it.
   - Exclude the current coin and move to the next coin.
5. Add the number of ways from both choices.
6. Return the total number of ways.

## Java Solution

```java
import java.util.Scanner;

class Main {

    static int countWays(int[] coins, int n, int m) {
        // A target of 0 means one valid way is found
        if (m == 0) {
            return 1;
        }

        // No coins left or target becomes negative
        if (n == 0 || m < 0) {
            return 0;
        }

        // Include the current coin or exclude it
        return countWays(coins, n, m - coins[n - 1])
                + countWays(coins, n - 1, m);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] coins = new int[n];

        for (int i = 0; i < n; i++) {
            coins[i] = sc.nextInt();
        }

        int m = sc.nextInt();

        System.out.println(countWays(coins, n, m));
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(2^M)` in the worst case.
* **Space Complexity:** `O(M)` due to the recursive call stack.
