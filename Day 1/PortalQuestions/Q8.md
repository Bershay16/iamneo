# Smallest Equilibrium Index

## Problem Statement

Help Rehan write a program that reads an array of `n` integers and finds the smallest equilibrium index. If no equilibrium index exists, print `-1`.

An equilibrium index is an index where the sum of all elements to its left is equal to the sum of all elements to its right.

## Input Format

The first line of input contains an integer `n`, representing the number of elements.

The second line contains `n` integers separated by spaces, representing the array elements.

## Output Format

Print:

```text
Equilibrium Index: <index>
```

where `<index>` is the smallest equilibrium index.

If no equilibrium index exists, print:

```text
Equilibrium Index: -1
```

## Constraints

* `1 ≤ n ≤ 100000`
* `-1000 ≤ array elements ≤ 1000`

## Sample Test Cases

### Case 1

**Input**

```text
5
1 2 3 4 6
```

**Output**

```text
Equilibrium Index: 3
```

### Case 2

**Input**

```text
4
1 2 3 4
```

**Output**

```text
Equilibrium Index: -1
```

## Approach

1. Calculate the total sum of all elements in the array.
2. Maintain a variable `leftSum` to store the sum of elements before the current index.
3. For each index, calculate the right-side sum as:
   `totalSum - leftSum - currentElement`
4. If `leftSum` and `rightSum` are equal, print the current index.
5. Since the array is checked from left to right, the first equilibrium index found is the smallest one.
6. If no equilibrium index is found, print `-1`.

## Java Solution

```java
import java.util.*;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] nums = new int[n];

        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }

        int totalSum = 0;
        int leftSum = 0;

        for (int num : nums) {
            totalSum += num;
        }

        for (int i = 0; i < n; i++) {
            int current = nums[i];
            int rightSum = totalSum - leftSum - current;

            if (leftSum == rightSum) {
                System.out.println("Equilibrium Index: " + i);
                return;
            }

            leftSum += current;
        }

        System.out.println("Equilibrium Index: -1");
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)`
