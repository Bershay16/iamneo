# Quadratic Probing in Hashing

## Problem Statement

Write a program to implement **Quadratic Probing in Hashing**.

If the slot `hash(x) % S` is full, then try `(hash(x) + 1*1) % S`.

If `(hash(x) + 1*1) % S` is also full, then try `(hash(x) + 2*2) % S`.

If `(hash(x) + 2*2) % S` is also full, then try `(hash(x) + 3*3) % S`.

This process is repeated for all the values of `i` until an empty slot is found.

## Input Format

The first line of input consists of the size of the array.

The second line of input consists of the array elements separated by a space.

The last line of input consists of the size of the hashtable.

## Output Format

Print the space-separated array elements after implementing the quadratic probing conditions mentioned in the problem statement.

## Sample Test Cases

### Case 1

**Input**

```text
7
50 700 76 85 92 73 101
7
```

**Output**

```text
700 50 85 73 101 92 76
```

## Approach

1. Read the number of elements.
2. Read the array elements.
3. Read the size of the hash table.
4. Create an empty hash table of the given size.
5. For each element, calculate its initial hash position using `x % S`.
6. If the position is occupied, use quadratic probing:
   `((x % S) + i * i) % S`
7. Continue until an empty position is found.
8. Place the element in that position.
9. Print the resulting hash table.

## Java Solution

```java
import java.util.*;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] nums = new int[n];

        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }

        int s = sc.nextInt();
        Integer[] result = new Integer[s];

        for (int i = 0; i < n; i++) {
            int x = nums[i];
            boolean placed = false;
            int position = 0;
            int hash = (x % s + s) % s;

            while (!placed && i < s) {
                position = (hash + i * i) % s;

                if (result[position] == null) {
                    result[position] = x;
                    placed = true;
                } else {
                    i++;
                }
            }
        }

        for (Integer num : result) {
            System.out.print(num + " ");
        }
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(n²)` in the worst case.
* **Space Complexity:** `O(S)`.
