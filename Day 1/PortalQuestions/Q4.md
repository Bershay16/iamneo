# Generate and Sort All Substrings

## Problem Statement

Meera is organizing all possible substrings of a word into sorted order. She is given a string, and her goal is to find and display all the contiguous substrings of that string.

For example, if the input string is `fun`, the output should list all possible substrings such as `f`, `fu`, `fun`, `u`, `un`, `n`.

The total number of substrings for a string of length `n` can be calculated using the formula `n(n+1)/2`.

Write a program to generate all substrings of the given string and print them in alphabetically sorted order.

## Input Format

The first line of input contains a string representing the input string.

## Output Format

The program should print all substrings of the input string in alphabetical order. Each substring should be printed on a separate line.

The substrings must include all possible contiguous combinations, starting from the smallest (1 character) up to the full length of the string.

## Constraints

* `1 ≤ length of string ≤ 200`
* String contains only lowercase characters.

## Approach

1. Read the input string.
2. Use two loops to generate every possible contiguous substring.
3. Store each substring in an `ArrayList`.
4. Sort the list alphabetically using `Collections.sort()`.
5. Print each substring on a separate line.

## Java Solution

```java
import java.util.*;

class Solution {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String str = input.nextLine();
        int n = str.length();

        ArrayList<String> result = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            StringBuilder sb = new StringBuilder();

            for (int j = i; j < n; j++) {
                sb.append(str.charAt(j));
                result.add(sb.toString());
            }
        }

        Collections.sort(result);

        for (String res : result) {
            System.out.println(res);
        }
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(n² log n)`
* **Space Complexity:** `O(n²)`
