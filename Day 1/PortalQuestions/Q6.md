# Longest Palindromic Substring

## Problem Statement

Ananya is building a text validation module for her linguistic research application where she needs to identify palindromic patterns within given strings. She wants to find the longest substring that reads the same forwards and backwards.

Given a string, determine the longest palindromic substring within it. If two substrings share the same maximum length, return the one appearing first in the string.

Write a program to find the longest palindromic substring using the two-pointer technique by expanding outward from each character as a center to check both odd-length and even-length palindromes.

## Input Format

The input consists of a string `s` representing the input string to be processed.

## Output Format

The output displays:

```text
Longest Palindromic Substring: <longest palindrome>
```

## Constraints

* `1 ≤ s.length ≤ 100`
* `s` consists of only lowercase alphabets.

## Sample Test Cases

### Case 1

**Input**

```text
babad
```

**Output**

```text
Longest Palindromic Substring: bab
```

### Case 2

**Input**

```text
cbbd
```

**Output**

```text
Longest Palindromic Substring: bb
```

## Approach

1. Consider every character as the center of an odd-length palindrome.
2. Consider every pair of adjacent characters as the center of an even-length palindrome.
3. Expand outward while the characters on both sides are equal.
4. Keep track of the longest palindrome found.
5. If two palindromes have the same length, keep the one that appears first.

## Java Solution

```java
import java.util.*;

class Solution {
    public static String longestPalindrome(String s) {
        int start = 0;
        int maxLength = 1;

        for (int i = 0; i < s.length(); i++) {
            int left = i;
            int right = i;

            while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
                if (right - left + 1 > maxLength) {
                    start = left;
                    maxLength = right - left + 1;
                }
                left--;
                right++;
            }

            left = i;
            right = i + 1;

            while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
                if (right - left + 1 > maxLength) {
                    start = left;
                    maxLength = right - left + 1;
                }
                left--;
                right++;
            }
        }

        return s.substring(start, start + maxLength);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        String s = sc.nextLine();

        System.out.println("Longest Palindromic Substring: " + longestPalindrome(s));

        sc.close();
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(n²)`
* **Space Complexity:** `O(1)`
