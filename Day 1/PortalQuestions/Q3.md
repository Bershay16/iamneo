# Longest Substring Without Repeating Characters

## Problem Statement

Priya is developing a password strength analyzer for a security application. One of the checks requires finding the length of the longest sequence of characters in a password where no character repeats. This helps measure the diversity and unpredictability of password segments.

Write a program to calculate the length of the longest substring in which all characters are unique.

## Input Format

The input consists of a string representing the text from which the longest substring without repeating characters needs to be extracted.

## Output Format

Print an integer representing the length of the longest substring without repeating characters.

## Constraints

* `1 ≤ length of string ≤ 30`
* The string contains only ASCII characters.

## Sample Test Cases

### Case 1

**Input**

```text
abcabcbb
```

**Output**

```text
3
```

### Case 2

**Input**

```text
klmnio
```

**Output**

```text
6
```

## Approach

1. Use a `HashSet` to store the characters in the current substring.
2. Maintain two pointers, `left` and `right`.
3. Move `right` through the string.
4. If the character is already present, remove characters from the left until the duplicate is removed.
5. Add the current character to the set.
6. Keep track of the maximum substring length.

## Java Solution

```java
import java.util.*;

class Solution {
    public static int lengthOfLongestSubstring(String s) {
        HashSet<Character> set = new HashSet<>();
        int left = 0;
        int max = 0;

        for (int right = 0; right < s.length(); right++) {
            while (set.contains(s.charAt(right))) {
                set.remove(s.charAt(left));
                left++;
            }

            set.add(s.charAt(right));
            max = Math.max(max, right - left + 1);
        }

        return max;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        System.out.println(lengthOfLongestSubstring(s));
        sc.close();
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)`
