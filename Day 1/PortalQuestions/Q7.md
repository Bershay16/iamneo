# Smallest Subarray With Sum at Least K

## Problem Statement

Help Neha write a program that reads an array of `n` positive integers and a target value `k`, and finds the length of the smallest subarray whose sum is at least `k`. If no such subarray exists, print `0`.

## Input Format

The first line of input contains an integer `n`, representing the number of elements.

The second line of input contains `n` space-separated integers representing the array elements.

The third line of input contains an integer `k`, representing the target sum.

## Output Format

Print:

```text
Smallest Length: <length>
```

where `<length>` is the length of the smallest subarray whose sum is at least `k`.

If no such subarray exists, print `0` as the length.

## Constraints

* `1 ≤ n ≤ 100000`
* `1 ≤ array elements ≤ 1000`
* `1 ≤ k ≤ 100000000`

## Sample Test Cases

### Case 1

**Input**

```text
5
1 4 4 4 8
8
```

**Output**

```text
Smallest Length: 1
```

### Case 2

**Input**

```text
6
1 2 3 4 5 6
11
```

**Output**

```text
Smallest Length: 2
```

## Approach

1. Use two pointers to maintain a sliding window.
2. Add elements to the current window and keep track of its sum.
3. When the sum becomes greater than or equal to `k`, update the minimum length.
4. Remove elements from the beginning of the window while the sum remains at least `k`.
5. Continue until all elements have been processed.
6. If no valid subarray is found, the minimum length remains `0`.

## Java Solution

```java
import java.util.Scanner;

class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] arr = new int[n];

        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        int k = sc.nextInt();
        int left = 0;
        int sum = 0;
        int min = n + 1;

        for (int right = 0; right < n; right++) {
            sum += arr[right];

            while (sum >= k) {
                min = Math.min(min, right - left + 1);
                sum -= arr[left];
                left++;
            }
        }

        if (min == n + 1) {
            min = 0;
        }

        System.out.println("Smallest Length: " + min);
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)`
