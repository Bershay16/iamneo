# Check for Duplicate Elements in an Array

## Problem Statement

Josh is working on a project that involves analyzing arrays of numbers. He needs to determine if an array contains any duplicate elements.

Write a program that takes an array as input, prints the elements of the array, and checks if there are any duplicate elements in the array.

## Input Format

The first line contains an integer `n`, representing the number of elements in the array.

The second line contains `n` space-separated integers representing the elements of the array.

## Output Format

The first line displays the elements of the array in a single line, separated by spaces.

The second line displays:

`The array contains duplicates.`

if there are any duplicate elements in the array.

Otherwise, it displays:

`The array does not contain duplicates.`

## Constraints

* `1 ≤ n ≤ 10`
* `0 ≤ nums[i] ≤ 1000`

## Sample Test Cases

### Case 1

**Input**

```text
5
2 4 3 4 1
```

**Output**

```text
2 4 3 4 1
The array contains duplicates.
```

### Case 2

**Input**

```text
4
1 2 3 4
```

**Output**

```text
1 2 3 4
The array does not contain duplicates.
```

## Approach

1. Read the number of elements `n`.
2. Read the array elements.
3. Print all the elements of the array.
4. Use a `HashSet` to keep track of elements that have already appeared.
5. If an element already exists in the set, print that the array contains duplicates.
6. If no duplicate is found, print that the array does not contain duplicates.

## Java Solution

```java
import java.util.Scanner;
import java.util.HashSet;

class DuplicateChecker {
    public static void checkDuplicates(int[] nums, int n) {
        for (int i = 0; i < n; i++) {
            System.out.print(nums[i] + " ");
        }

        System.out.println();

        HashSet<Integer> set = new HashSet<>();

        for (int i = 0; i < n; i++) {
            if (!set.add(nums[i])) {
                System.out.println("The array contains duplicates.");
                return;
            }
        }

        System.out.println("The array does not contain duplicates.");
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] arr = new int[n];

        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        DuplicateChecker.checkDuplicates(arr, n);

        sc.close();
    }
}
```

## Complexity Analysis

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)`
