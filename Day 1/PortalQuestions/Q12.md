# Stack Using Linked List

## Problem Statement

Raghav is learning about stacks and has implemented a simple stack using a linked list. The stack supports three operations: push, pop and display.

## Input

- `1`: Push an element into the stack, followed by its value.
- `2`: Pop an element from the stack.
- `3`: Display the stack.
- `4`: Exit.
- Any choice greater than `4` prints `Wrong choice`.

## Output

- Push: `Node is Inserted`
- Pop: `Popped Element: X` or `EMPTY STACK`
- Display: `The stack is: X Y Z` or `EMPTY STACK`
- Invalid choice: `Wrong choice`

## Code Constraints

- `1 ≤ element value ≤ 10000`
- Choice can be any integer; valid choices are `1, 2, 3, 4`.
- Invalid choices trigger `Wrong choice`.

## Java Code

```java
import java.util.*;

class Node {
    int data;
    Node next;

    Node(int data) {
        this.data = data;
    }
}

class Stack {
    Node top;

    void push(int x) {
        Node n = new Node(x);
        n.next = top;
        top = n;
        System.out.println("Node is Inserted");
    }

    void pop() {
        if (top == null) {
            System.out.println("EMPTY STACK");
            return;
        }
        System.out.println("Popped Element: " + top.data);
        top = top.next;
    }

    void display() {
        if (top == null) {
            System.out.println("EMPTY STACK");
            return;
        }

        System.out.print("The stack is:");
        for (Node t = top; t != null; t = t.next)
            System.out.print(" " + t.data);
        System.out.println();
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        Stack s = new Stack();

        while (true) {
            int choice = sc.nextInt();

            switch (choice) {
                case 1:
                    s.push(sc.nextInt());
                    break;
                case 2:
                    s.pop();
                    break;
                case 3:
                    s.display();
                    break;
                case 4:
                    return;
                default:
                    System.out.println("Wrong choice");
            }
        }
    }
}
```

## Time Complexity

- Push: `O(1)`
- Pop: `O(1)`
- Display: `O(N)`

## Space Complexity
