# Singly Linked List — Sort in Ascending Order

## Problem Statement

Create a singly linked list by inserting N elements at the end. Sort the elements in ascending order and display them.

## Input

- First line: Integer N, number of elements.
- Second line: N space-separated integers.

## Output

Print the sorted linked-list elements as space-separated integers.

## Input Description

N represents the number of elements, followed by the elements of the linked list.

## Output Description

The elements sorted in ascending order.

## Java Code

```java
import java.util.*;

class Node {
    int data;
    Node next;

    Node(int data) {
        this.data = data;
    }
}

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        Node head = null, tail = null;

        for (int i = 0; i < n; i++) {
            Node newNode = new Node(sc.nextInt());

            if (head == null)
                head = tail = newNode;
            else {
                tail.next = newNode;
                tail = newNode;
            }
        }

        for (Node i = head; i != null; i = i.next) {
            for (Node j = i.next; j != null; j = j.next) {
                if (i.data > j.data) {
                    int temp = i.data;
                    i.data = j.data;
                    j.data = temp;
                }
            }
        }

        for (Node i = head; i != null; i = i.next)
            System.out.print(i.data + " ");
    }
}
```

## Time Complexity

O(N²)

## Space Complexity

O(N)
