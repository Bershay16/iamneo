# Printer Queue Using Linked List

## Problem Statement

Implement a printer queue using a linked list. Each print job is represented by the number of pages.

- Enqueue: Add a print job to the end of the queue.
- Dequeue: Remove and process the next print job.
- Display: Display the print jobs in the queue.
- Exit: Terminate the program.

## Input

The input consists of options:

- `1`: Enqueue, followed by the number of pages.
- `2`: Dequeue.
- `3`: Display the queue.
- `4`: Exit.

## Input Description

The program accepts an operation option. For option `1`, the next input is the number of pages. Options `2` and `3` require no additional input. Input continues until option `4` is entered.

## Output

- Option `1`: `Print job with X pages is enqueued.`
- Option `2`: `Processing print job: X pages` if the queue is not empty; otherwise `Queue is empty.`
- Option `3`: `Print jobs in the queue: X pages Y pages` if the queue is not empty; otherwise `Queue is empty.`
- Option `4`: The program terminates.
- Invalid option: `Invalid option.`

## Output Description

The output displays the result of the selected queue operation.

## Java Code

```java
import java.util.*;

class Node {
    int data;
    Node next;

    Node(int data) {
        this.data = data;
    }
}

class Main {
    static Node front, rear;

    static void enqueue(int x) {
        Node n = new Node(x);
        if (rear == null)
            front = rear = n;
        else {
            rear.next = n;
            rear = n;
        }
        System.out.println("Print job with " + x + " pages is enqueued.");
    }

    static void dequeue() {
        if (front == null) {
            System.out.println("Queue is empty.");
            return;
        }
        System.out.println("Processing print job: " + front.data + " pages");
        front = front.next;
        if (front == null)
            rear = null;
    }

    static void display() {
        if (front == null) {
            System.out.println("Queue is empty.");
            return;
        }

        System.out.print("Print jobs in the queue:");
        for (Node t = front; t != null; t = t.next)
            System.out.print(" " + t.data + " pages");
        System.out.println();
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        while (true) {
            int op = sc.nextInt();

            if (op == 1)
                enqueue(sc.nextInt());
            else if (op == 2)
                dequeue();
            else if (op == 3)
                display();
            else if (op == 4)
                break;
            else
                System.out.println("Invalid option.");
        }
    }
}
```

## Time Complexity

- Enqueue: O(1)
- Dequeue: O(1)
- Display: O(N)

## Space Complexity

O(N)
