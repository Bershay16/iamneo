# Decode Sequence

## Problem Statement

Given a sequence containing `I` and `D`, where `I` represents an increasing sequence and `D` represents a decreasing sequence, decode it into a sequence of numbers with no repeated digits.

## Input

A string containing only uppercase characters `I` and `D`.

## Input Description

The input is a sequence of `I` and `D` characters.

## Output

Print the decoded sequence.

## Output Description

The output is the decoded sequence of numbers satisfying the given increasing and decreasing pattern.

## Java Code

```java
import java.util.*;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine();
        Stack<Integer> st = new Stack<>();

        for (int i = 0; i <= s.length(); i++) {
            st.push(i + 1);

            if (i == s.length() || s.charAt(i) == 'I') {
                while (!st.isEmpty())
                    System.out.print(st.pop());
            }
        }
    }
}
```

## Time Complexity

O(N)

## Space Complexity

O(N)
