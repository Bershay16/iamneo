# Minimum Number of Barbers

## Problem Statement

Given the arrival and leaving times of customers at a barbershop, find the minimum number of barbers required so that no customer has to wait.

Use a greedy algorithm to find the maximum number of customers present at the shop at the same time.

## Input Format

The first line contains an integer `n`, the number of customers.

The second line contains `n` space-separated integers representing arrival times.

The third line contains `n` space-separated integers representing leaving times.

## Input Description

- `n` is the number of customers.
- Arrival times specify when customers enter the barbershop.
- Leaving times specify when customers leave after service.

## Output Format

Print the minimum number of barbers required.

## Output Description

The output is the maximum number of customers present in the barbershop at the same time.

## Java Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] a = new int[n];
        int[] b = new int[n];

        for (int i = 0; i < n; i++)
            a[i] = sc.nextInt();

        for (int i = 0; i < n; i++)
            b[i] = sc.nextInt();

        Arrays.sort(a);
        Arrays.sort(b);

        int i = 0, j = 0, count = 0, max = 0;

        while (i < n && j < n) {
            if (a[i] < b[j]) {
                count++;
                max = Math.max(max, count);
                i++;
            } else {
                count--;
                j++;
            }
        }

        System.out.println(max);
    }
}
```

## Time Complexity

`O(n log n)`

## Space Complexity

`O(n)`
