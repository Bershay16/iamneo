# Breadth-First Search (BFS) in Directed Graph

## Problem Statement

A university has a set of departments connected by research collaborations. These collaborations form a directed graph where each department is represented as a vertex, and each directed edge represents a one-way collaboration from one department to another.

Implement the breadth-first search (BFS) algorithm to determine the order of department visits starting from a specific department.

## Input Format

The first line contains two integers `n` and `e`, where `n` is the number of vertices and `e` is the number of directed edges.

The next `e` lines contain two integers `a` and `b`, representing a directed edge from `a` to `b`.

The next line contains an integer `p`, representing the starting vertex for BFS traversal.

## Output Format

Print the space-separated vertices in the order they are visited during BFS traversal starting from the given vertex.

When multiple unvisited neighbors are available, visit them in increasing order of vertex index.

## Code Constraints

- `1 ≤ n ≤ 8`
- `1 ≤ e ≤ 10`
- `0 ≤ a, b < n`
- `0 ≤ p < n`

## Java Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int e = sc.nextInt();

        ArrayList<Integer>[] graph = new ArrayList[n];

        for (int i = 0; i < n; i++)
            graph[i] = new ArrayList<>();

        for (int i = 0; i < e; i++) {
            int a = sc.nextInt();
            int b = sc.nextInt();
            graph[a].add(b);
        }

        for (int i = 0; i < n; i++)
            Collections.sort(graph[i]);

        int start = sc.nextInt();
        boolean[] visited = new boolean[n];
        Queue<Integer> q = new LinkedList<>();

        q.add(start);
        visited[start] = true;

        while (!q.isEmpty()) {
            int u = q.poll();
            System.out.print(u + " ");

            for (int v : graph[u]) {
                if (!visited[v]) {
                    visited[v] = true;
                    q.add(v);
                }
            }
        }
    }
}
```

## Complexity

Time: `O(n + e)`

Space: `O(n + e)`
