# Question 2 — Undirected Graph Using Adjacency List

## Topic
**Graph — Undirected Graph, Adjacency List, Linked List**

---

## Problem Statement

Sanjay is developing a program to represent an undirected graph using an adjacency list. The graph contains five vertices. Seven edges are added between the vertices given by the input.

If the same vertex value is supplied more than once, the corresponding edges may form self-loops or parallel edges.

The vertices entered by the user correspond to nodes `a`, `b`, `c`, `d`, and `e` respectively.

Edges exist between the following vertex pairs:

```text
(a, b)
(a, e)
(b, c)
(b, d)
(b, e)
(c, d)
(d, e)
```

Your task is to construct the graph using adjacency list representation and display the adjacency list of each vertex.

**Important:** Adjacent vertices are printed in reverse order of edge insertion.

---

## Input Format

The first line of input consists of five space-separated integers `a`, `b`, `c`, `d`, and `e`, representing the vertices to be connected.

The graph is fixed with 5 vertices (`0` to `4`) and the following edges are added in order:

```text
a-b
a-e
b-c
b-d
b-e
c-d
d-e
```

The input values correspond to the five graph vertices:

```text
0 → a
1 → b
2 → c
3 → d
4 → e
```

---

## Output Format

For each vertex from `0` to `4` in order, print a line in the format:

```text
vertex X: head -> Y -> Z
```

where `X` is the vertex and `Y`, `Z`, etc. are the adjacent vertices currently present in that vertex's adjacency list.

The adjacent vertices must be printed in **reverse order of edge insertion**, meaning the most recently inserted edge appears first.

If a vertex has no adjacent vertices, print only:

```text
vertex X: head
```

Refer to the sample output for formatting specifications.

---

## Code Constraints

The given test cases fall under the following constraints:

```text
0 <= a, b, c, d, e <= 4
```

Vertex values are not guaranteed to be distinct. Repeated values may occur and can result in self-loops or parallel edges in the adjacency list.

## Approach

1. Create a `Node` class containing:
   - The adjacent vertex value.
   - A reference to the next node.
2. Create an adjacency-list structure containing one linked list for every vertex.
3. Since the graph is undirected, whenever an edge `(u, v)` is inserted:
   - Add `v` to the adjacency list of `u`.
   - Add `u` to the adjacency list of `v`.
4. Insert every new adjacent vertex at the **beginning** of the linked list.
5. Inserting at the beginning automatically makes the adjacency list appear in reverse order of edge insertion.
6. Traverse each linked list and print its vertices from head to tail.

---

## Java Code

```java
import java.util.*;

class Node{
    int value;
    Node next;

    Node(int value){
        this.value = value;
        this.next = null;
    }
}

class Graph{
    Node[] adj;

    Graph(int vertices){
        adj = new Node[vertices];
    }

    void addEdge(int u, int v){
        Node temp1 = new Node(v);
        temp1.next = adj[u];
        adj[u] = temp1;

        Node temp2 = new Node(u);
        temp2.next = adj[v];
        adj[v] = temp2;
    }

    void display(){
        for(int i = 0; i < adj.length; i++){
            System.out.print("vertex " + i + ": head");

            Node temp = adj[i];

            while(temp != null){
                System.out.print(" -> " + temp.value);
                temp = temp.next;
            }

            System.out.println();
        }
    }
}

class Solution{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);

        int[] vertex = new int[5];

        for(int i = 0; i < 5; i++){
            vertex[i] = sc.nextInt();
        }

        Graph graph = new Graph(5);

        graph.addEdge(vertex[0], vertex[1]);
        graph.addEdge(vertex[0], vertex[4]);
        graph.addEdge(vertex[1], vertex[2]);
        graph.addEdge(vertex[1], vertex[3]);
        graph.addEdge(vertex[1], vertex[4]);
        graph.addEdge(vertex[2], vertex[3]);
        graph.addEdge(vertex[3], vertex[4]);

        graph.display();
    }
}
```

## Important Implementation Detail

The adjacency list is implemented manually using a linked list.

No built-in `ArrayList`, `LinkedList`, or graph data structure is used for storing the adjacency lists.

Each new edge is inserted at the beginning of the corresponding linked list:

```text
New Node → Old Head
```

Therefore, the most recently inserted adjacent vertex appears immediately after `head`, which produces the required reverse order of edge insertion.

---

## Complexity

### Edge Insertion

Each edge is inserted into two adjacency lists.

- Time: `O(1)` per insertion

### Display

Every adjacency node is visited once.

- Time: `O(V + E)`

where:

- `V` = number of vertices
- `E` = number of edges

### Space Complexity

- `O(V + E)`
