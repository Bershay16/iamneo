# Question 1 — Alphabet Tree Search

## Topic
**Binary Search Tree (BST) — Insertion and Searching**

---

## Problem Statement

Toy loves trees, especially alphabet trees! He wants to build his alphabet tree by inserting characters one by one.

Given a sequence of characters, Toy needs to construct a binary search tree where each node contains a character.

After constructing the tree, Toy wants to search for a specific character in the tree to see if it exists or not.

Write a program to help Toy construct his alphabet tree and perform the search.

---

## Input Format

- The first line contains an integer `N`, denoting the number of characters Toy wants to insert into the tree.
- The second line contains `N` space-separated characters, representing the characters Toy wants to insert into the tree.
- The third line contains a single character `V`, representing the character Toy wants to search for in the tree.

---

## Output Format

- If the character `V` is found in the constructed alphabet tree, print:

```text
Character - V is Found
```

- If the character `V` is not found in the constructed alphabet tree, print:

```text
Character - V is Not Found
```

Refer to the sample output for the formatting specifications.

---

## Code Constraints

```text
1 <= N <= 10
```

Each character inserted into the tree is an uppercase English letter (`A` to `Z`).

## Approach

1. Create a `Node` class containing:
   - Character value
   - Left child
   - Right child
2. Create a `Tree` class containing the root node.
3. Insert every character according to Binary Search Tree rules:
   - Smaller characters go to the left.
   - Greater or equal characters go to the right.
4. Search for the given character:
   - If the current node is `null`, the character does not exist.
   - If the current node contains the character, return `true`.
   - If the character is smaller, search the left subtree.
   - Otherwise, search the right subtree.
5. Print the required result.

## Java Code

```java
import java.util.*;

class Node{
    char value;
    Node left;
    Node right;

    Node(){}

    Node(char value){
        this.value = value;
        right = null;
        left = null;
    }
}

class Tree{
    Node root;

    Tree(){}

    Tree(char value){
        root = new Node(value);
    }

    Node insert(Node root, char value){
        if(root == null){
            root = new Node(value);
            return root;
        }

        if(value < root.value){
            root.left = insert(root.left, value);
        }
        else{
            root.right = insert(root.right, value);
        }

        return root;
    }

    boolean search(Node root, char search){
        if(root == null){
            return false;
        }

        if(root.value == search){
            return true;
        }
        else if(root.value < search){
            return search(root.right, search);
        }
        else{
            return search(root.left, search);
        }
    }
}

class Solution{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        Tree tree = new Tree();

        for(int i = 0; i < n; i++){
            tree.root = tree.insert(tree.root, sc.next().charAt(0));
        }

        char search = sc.next().charAt(0);

        boolean present = tree.search(tree.root, search);

        if(present)
            System.out.println("Character - " + search + " is Found");
        else
            System.out.println("Character - " + search + " is Not Found");
    }
}
```
