# Question 4 — Minimum Number of Coins

## Topic
**Greedy Algorithm — Coin Change**

---

## Problem Statement

Betty is organizing a charity event and needs to collect a specific amount of money using the least number of coins from given denominations.

Help Betty by writing a program using a **greedy algorithm** that calculates the minimum number of coins required to achieve the target amount.

If it is not possible to reach the exact amount with the given coins, print `-1`.

### Note

Assume that you have an infinite number of coins of different kinds.

---

## Example 1

### Input

```text
12 5
11
```

### Output

```text
3
```

### Explanation

The target amount `11` can be formed using:

```text
11 = 5 + 5 + 1
```

Therefore, the minimum number of coins is:

```text
3
```

## Approach

1. Read all coin denominations.
2. Sort the denominations in descending order.
3. Start with the largest denomination.
4. Take as many coins of the current denomination as possible without exceeding the target.
5. Subtract the selected value from the remaining target.
6. Continue with the next denomination.
7. If the remaining target becomes `0`, print the number of coins used.
8. If the target cannot be reduced to `0`, print `-1`.

---

## Java Code

```java
import java.util.*;

class Solution {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        String[] input = sc.nextLine().split(" ");
        int[] coins = new int[input.length];

        for (int i = 0; i < input.length; i++) {
            coins[i] = Integer.parseInt(input[i]);
        }

        int target = sc.nextInt();

        Arrays.sort(coins);

        int count = 0;

        for (int i = coins.length - 1; i >= 0; i--) {

            if (target >= coins[i]) {
                count += target / coins[i];
                target %= coins[i];
            }
        }

        if (target == 0)
            System.out.println(count);
        else
            System.out.println(-1);
    }
}
```

## Important Logic

For every denomination:

```text
number of coins = target / coin
```

Then update the remaining target:

```text
target = target % coin
```

The denominations are processed from **largest to smallest**.

Example:

```text
Coins: 12 5 1
Target: 11
```

Since `12 > 11`, skip `12`.

Take:

```text
11 / 5 = 2
```

Remaining:

```text
11 % 5 = 1
```

Then take:

```text
1 / 1 = 1
```

Total:

```text
2 + 1 = 3 coins
```
