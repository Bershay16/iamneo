# Question 3 — Longest Consecutive Character Path in a Matrix

## Topic
**Matrix / Graph Traversal — DFS, Recursion, Backtracking**

---

## Problem Statement

Given an `M × N` matrix of characters, find the length of the longest path in the matrix starting from a given character.

All characters along the path must be in alphabetically increasing and consecutive order (for example, `a → b → c → ...`).

Movement is allowed in all eight directions:

- North
- South
- East
- West
- North-East
- North-West
- South-East
- South-West

Each cell may be visited at most once per path.

Use **Depth-First Search (DFS)** to solve this problem.

If the starting character exists in the matrix but has no valid consecutive neighbor, the length of the longest path is `1`, because the starting character itself counts as a path of length `1`.

---

## Example

Consider the following matrix:

```text
D E H X B
A O G P E
D D C F D
E B E A S
C D Y E N
```

Starting character:

```text
C
```

The length of the longest path with consecutive characters starting from `C` is `6`.

The longest path is:

```text
C(2,2) → D(2,1) → E(3,2) → F(2,3) → G(1,2) → H(0,2)
```

Therefore:

```text
6
```

The first line of input is an integer `n` representing the row size.

The second line of input is an integer `m` representing the column size.

The following `n` lines of input are the characters of the matrix.

The last line of input is the character for which the length of the longest path is to be found.

## Approach

1. Read the matrix and the starting character.
2. Search the entire matrix for cells containing the starting character.
3. For every occurrence of the starting character, perform DFS.
4. From the current cell, check all eight possible directions.
5. A neighboring cell can be visited only when its character is exactly one greater than the current character.
6. Mark the current cell as visited before exploring its neighbors.
7. After exploring all valid neighbors, unmark the cell so that it can be used in another independent path.
8. The DFS returns the maximum path length starting from that cell.
9. Keep the maximum result among all occurrences of the starting character.
10. The starting cell contributes `1` to the path length.

---

## Java Code

```java
import java.util.*;

class Solution{

    static int n, m;
    static char[][] matrix;
    static boolean[][] visited;

    static int[] row = {-1, -1, -1, 0, 0, 1, 1, 1};
    static int[] col = {-1, 0, 1, -1, 1, -1, 0, 1};

    static int dfs(int r, int c){

        visited[r][c] = true;

        int maxLength = 1;

        for(int i = 0; i < 8; i++){

            int nr = r + row[i];
            int nc = c + col[i];

            if(nr >= 0 && nr < n && nc >= 0 && nc < m
                    && !visited[nr][nc]
                    && matrix[nr][nc] == matrix[r][c] + 1){

                maxLength = Math.max(maxLength, 1 + dfs(nr, nc));
            }
        }

        visited[r][c] = false;

        return maxLength;
    }

    public static void main(String[] args){

        Scanner sc = new Scanner(System.in);

        n = sc.nextInt();
        m = sc.nextInt();

        matrix = new char[n][m];
        visited = new boolean[n][m];

        for(int i = 0; i < n; i++){
            for(int j = 0; j < m; j++){
                matrix[i][j] = sc.next().charAt(0);
            }
        }

        char startChar = sc.next().charAt(0);

        int answer = 0;

        for(int i = 0; i < n; i++){
            for(int j = 0; j < m; j++){

                if(matrix[i][j] == startChar){
                    answer = Math.max(answer, dfs(i, j));
                }
            }
        }

        System.out.println(
            "The length of the longest path with consecutive characters starting from character "
            + startChar + " is " + answer
        );
    }
}
```

## Important Implementation Detail

The matrix can be considered as a graph where:

- Each cell is a node.
- An edge exists between two cells if they are adjacent in one of the eight directions.
- The edge can be followed only when the next character is exactly one alphabetically greater.

For example:

```text
C → D → E → F → G → H
```

The `visited` matrix prevents the same cell from being used twice in the same path.

The cell is reset to `false` after DFS returns so that it can participate in other possible paths.

---

## Complexity

Let the matrix contain `N × M` cells.

### Time Complexity

In the worst case, DFS explores possible paths through the matrix.

```text
O(N × M × 8^L)
```

where `L` is the maximum possible path length.

Since the constraints are:

```text
N, M <= 5
```

the matrix is small enough for this DFS and backtracking approach.

### Space Complexity

```text
O(N × M + L)
```

- `O(N × M)` for the visited matrix.
- `O(L)` for the recursive DFS call stack.
