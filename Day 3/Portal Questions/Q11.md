# Minimum Number of Jumps

## Problem Statement

A robotics company is developing an autonomous delivery robot that must travel across a sequence of checkpoints. The robot starts at the first checkpoint and needs to reach the final checkpoint using the minimum number of jumps.

Each checkpoint contains a number representing the maximum number of checkpoints the robot can jump forward from its current position. For example, if the value at a checkpoint is `3`, the robot can jump to any of the next 1, 2, or 3 checkpoints.

Implement a greedy algorithm to determine the minimum number of jumps required to reach the last checkpoint.

It is guaranteed that the last checkpoint is always reachable.

## Input Format

The input consists of a single line containing space-separated integers.

Each integer represents the maximum jump length available from that checkpoint.

## Output Format

The output prints a single integer representing the minimum number of jumps required to reach the last checkpoint.

## Code Constraints

- `1 ≤ n ≤ 20`
- `0 ≤ jump[i] ≤ 10`
- The last checkpoint is always reachable.

## Java Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        ArrayList<Integer> a = new ArrayList<>();

        while (sc.hasNextInt())
            a.add(sc.nextInt());

        int jumps = 0, end = 0, far = 0;

        for (int i = 0; i < a.size() - 1; i++) {
            far = Math.max(far, i + a.get(i));

            if (i == end) {
                jumps++;
                end = far;
            }
        }

        System.out.println(jumps);
    }
}
```

## Complexity

Time: `O(n)`

Space: `O(n)`
