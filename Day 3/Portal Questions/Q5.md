# Question 5 — Find the Largest Value in Each Tree Row

## Topic
**Binary Tree — Level Order Traversal (BFS)**

---

## Problem Statement

Given the root of a binary tree, return an array containing the largest value in each row of the tree (0-indexed).

- Row 0 is the root.
- Row 1 contains the root's children.
- Row 2 contains their children.
- And so on.

The binary tree is provided as a comma-separated level-order array using 0-based indexing.

For a node at index `i`:
- Left child is at index `2*i + 1`
- Right child is at index `2*i + 2`

The value `null` indicates that no node exists at that position.

---

## Example 1

### Input

```text
1,3,2,5,3,null,9
```

### Binary Tree

```text
        1
       / \
      3   2
     / \   \
    5   3   9
```

### Output

```text
[1, 3, 9]
```

### Explanation

- Row 0 contains `1` → largest value = `1`
- Row 1 contains `3, 2` → largest value = `3`
- Row 2 contains `5, 3, 9` → largest value = `9`

Therefore:

```text
[1, 3, 9]
```

## Input Format

A single line containing the values of the binary tree in level-order, with each value separated by a comma.

Use `null` to indicate a missing node.

If the tree is empty, the input line will be empty.

---

## Output Format

Print the largest value in each row as a single line, formatted as a list in square brackets, with values separated by a comma and a space.

If the tree is empty, print:

```text

```

## Approach

Use **Breadth-First Search (BFS)** with a queue.

1. Convert the level-order input into tree nodes.
2. Add the root to a queue.
3. Process one complete level at a time.
4. For every level:
   - Find the number of nodes currently in the queue.
   - Process exactly those nodes.
   - Keep track of the maximum value in that level.
   - Add their non-null children to the queue.
5. Add the maximum value of each level to the result.
6. Print the result in the required format.

## Java Code

```java
import java.util.*;

class Solution {

    static class Node {
        int value;
        Node left, right;

        Node(int value) {
            this.value = value;
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        String input = sc.nextLine().trim();

        if (input.isEmpty()) {
            System.out.println("[]");
            return;
        }

        String[] values = input.split(",");

        if (values[0].equals("null")) {
            System.out.println("[]");
            return;
        }

        Node root = new Node(Integer.parseInt(values[0]));

        Queue<Node> buildQueue = new LinkedList<>();
        buildQueue.offer(root);

        int i = 1;

        while (!buildQueue.isEmpty() && i < values.length) {

            Node current = buildQueue.poll();

            if (i < values.length && !values[i].equals("null")) {
                current.left = new Node(Integer.parseInt(values[i]));
                buildQueue.offer(current.left);
            }
            i++;

            if (i < values.length && !values[i].equals("null")) {
                current.right = new Node(Integer.parseInt(values[i]));
                buildQueue.offer(current.right);
            }
            i++;
        }

        Queue<Node> queue = new LinkedList<>();
        queue.offer(root);

        ArrayList<Integer> result = new ArrayList<>();

        while (!queue.isEmpty()) {

            int size = queue.size();
            int max = Integer.MIN_VALUE;

            for (int j = 0; j < size; j++) {

                Node current = queue.poll();

                max = Math.max(max, current.value);

                if (current.left != null)
                    queue.offer(current.left);

                if (current.right != null)
                    queue.offer(current.right);
            }

            result.add(max);
        }

        System.out.println(result);
    }
}
```

## Key Idea

The important part is processing **one complete tree level at a time**.

```java
int size = queue.size();
```

This gives the number of nodes in the current level.

Then process exactly `size` nodes:

```java
for (int j = 0; j < size; j++) {
    Node current = queue.poll();
}
```

While processing them, maintain:

```java
max = Math.max(max, current.value);
```

After finishing the level:

```java
result.add(max);
```

This gives the largest value from every tree row.

### Time Complexity
