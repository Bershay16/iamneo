# Kth Smallest Element in a Binary Search Tree

## Problem Statement

Hidhan is fascinated by binary search trees (BSTs) and is learning about their properties.

He wants to develop a program that takes a series of characters as input and constructs a binary search tree from those characters. After constructing the BST, he wants to find the smallest element in the tree.

## Input Format

The first line contains an integer `n`, representing the number of characters to be inserted into the BST.

The next line contains `n` space-separated characters representing the elements to be inserted into the BST.

The next line contains an integer `k`, representing the kth smallest element to be found.

## Output Format

If the input is valid, print the single character, kth smallest character.

If the input is invalid (e.g., `k` is greater than `n` or the tree is empty), print `Invalid value of k`.

## Code Constraints

- `1 ≤ N ≤ 20`
- `1 ≤ K ≤ N`
- Data for each node is an uppercase character.

## Java Code

```java
import java.util.*;

class Node {
    char data;
    Node left, right;

    Node(char data) {
        this.data = data;
    }
}

public class Main {
    static Node insert(Node root, char data) {
        if (root == null)
            return new Node(data);

        if (data < root.data)
            root.left = insert(root.left, data);
        else
            root.right = insert(root.right, data);

        return root;
    }

    static void inorder(Node root, int[] k, char[] ans) {
        if (root == null || k[0] == 0)
            return;

        inorder(root.left, k, ans);

        k[0]--;
        if (k[0] == 0)
            ans[0] = root.data;

        inorder(root.right, k, ans);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        Node root = null;

        for (int i = 0; i < n; i++)
            root = insert(root, sc.next().charAt(0));

        int k = sc.nextInt();

        if (k < 1 || k > n) {
            System.out.println("Invalid value of k");
            return;
        }

        int[] count = {k};
        char[] ans = {0};

        inorder(root, count, ans);
        System.out.println(ans[0]);
    }
}
```

## Complexity

Time: `O(n)`

Space: `O(n)`
