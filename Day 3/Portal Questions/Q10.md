# Find All Possible Paths in a Directed Graph

## Problem Statement

James is working on a mapping application for a delivery service. He needs to calculate all possible routes between two delivery points in a city, represented as a directed graph. Each intersection is a vertex, and each road between intersections is directed.

Given a graph with multiple intersections and roads, find all possible paths from a source intersection to a destination intersection.

## Input Format

The first line contains an integer `V`, representing the number of intersections (vertices) in the city.

The second line contains an integer `E`, representing the number of roads (edges) in the city.

The next `E` lines contain two space-separated integers `u` and `v`, indicating a directed road from intersection `u` to intersection `v`.

The next line contains an integer representing the source intersection.

The last line contains an integer representing the destination intersection.

## Output Format

Print all possible paths from the source intersection to the destination intersection. Each path should be printed on a separate line, with the intersections in the path separated by a single space.

## Code Constraints

- `1 ≤ V ≤ 20`
- `0 ≤ E ≤ V*(V-1)`
- `0 ≤ u, v < V`
- `u ≠ v`
- `0 ≤ source, destination < V`

## Java Code

```java
import java.util.*;

public class Main {
    static ArrayList<Integer>[] graph;

    static void dfs(int u, int dest, ArrayList<Integer> path) {
        path.add(u);

        if (u == dest) {
            for (int x : path)
                System.out.print(x + " ");
            System.out.println();
        } else {
            for (int v : graph[u])
                dfs(v, dest, path);
        }

        path.remove(path.size() - 1);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int e = sc.nextInt();

        graph = new ArrayList[n];

        for (int i = 0; i < n; i++)
            graph[i] = new ArrayList<>();

        for (int i = 0; i < e; i++)
            graph[sc.nextInt()].add(sc.nextInt());

        int source = sc.nextInt();
        int destination = sc.nextInt();

        dfs(source, destination, new ArrayList<>());
    }
}
```

## Complexity

Time: `O(V + E)` per path

Space: `O(V)`
